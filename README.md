# 叠 · 暮色塔（Dusk Tower）

方块来回滑动，在它对齐时落下。歪出来的那一截会被切掉 —— 切得越准，塔越细越高。

## 玩法

- **落下**：空格 / 点击 / 轻触屏幕
- **暂停**：P / Esc / 右上角按钮

## 场景

塔越高，看到的越多：

| 高度 | 能看到 |
|---|---|
| 地面 | 树、房子（窗户亮着）、栅栏、路灯 |
| 380 m 起 | 小鸟 |
| 640 m 起 | 云 |
| 950 m 起 | 热气球 |
| 1400 m 起 | 飞机（带闪烁的航行灯） |
| 1100 m 起 | 星空与月亮，越高越亮 |

## 特点

- **单文件、零依赖、零外链** —— 一个 HTML 打开就能玩
- 等距投影，色相沿高度连续旋转（塔本身就是色阶）
- 相机只记录世界坐标锚点，窗口尺寸变化不会跳位
- 触屏 / 鼠标 / 键盘都支持；触屏设备会自动切换成触屏提示
- 适配手机竖屏、小屏安卓与横屏

## 调试开关

- `?demo=24` —— 自动叠 24 层，用于截图或演示
- `?touch=1` / `?touch=0` —— 强制触屏 / 桌面 UI
